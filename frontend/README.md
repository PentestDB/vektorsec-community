This is the [Next.js 16](https://nextjs.org/) frontend for Pentest Copilot.

## Prerequisites

- **Node.js 22+**
- **pnpm 9+** — install via `corepack enable`

## Getting Started

Install dependencies and start the development server:

```bash
pnpm install
pnpm run dev
```

Open [http://localhost:3001](http://localhost:3001) with your browser to see the result.

The dev server uses [Turbopack](https://turbo.build/pack) for fast refresh. You can start editing pages by modifying files in `src/app/`. The page auto-updates as you edit.

## Available Scripts

| Command          | Description                        |
| ---------------- | ---------------------------------- |
| `pnpm run dev`   | Start dev server with Turbopack    |
| `pnpm run build` | Create production build            |
| `pnpm run start` | Start production server            |
| `pnpm run lint`  | Run ESLint                         |
